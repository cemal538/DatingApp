# DatingApp

A full-stack dating application built while following 
"Build an app with ASP.NET Core and Angular from scratch" 
by Neil Cummings on Udemy.

Used as a hands-on learning project to deepen my .NET and 
Angular skills outside of work.

## Tech Stack

**Backend**
- ASP.NET Core Web API
- Entity Framework Core
- ASP.NET Identity (JWT auth)
- SignalR (real-time messaging)
- AutoMapper
- Cloudinary (photo storage)

**Frontend**
- Angular
- TypeScript
- Bootstrap / NgxBootstrap
- RxJS

## Features
- JWT-based authentication and authorization
- User profiles with multi-photo upload
- Real-time private messaging (SignalR)
- Like/match system
- Member filtering, sorting, and pagination
- Role-based admin panel

## What I took from it
- SignalR hub patterns for real-time features
- JWT auth flow end-to-end (token generation, refresh, guards)
- EF Core relationships and migrations on a non-trivial domain
- Repository pattern and clean separation between API and data layer
